## The entry

The entry letter is **"A"** — A for coffee.

## Why A wins

The judge picks the letter whose choice of coffee or tea feels more vivid,
funnier, or truer, and "A" beats "B" on all three:

- **Vivid:** "A" is the first letter — the lead answer, the one that comes
  first and loudest. That matches coffee itself: bold, dark, in-your-face,
  the drink that wakes you up and announces itself. Tea is gentle and
  second; "B" reads as the runner-up letter for the runner-up drink.
- **Funnier:** "A" is also the top grade. Coffee gets an A — a small wink
  the judge can catch in a single character, where "B" carries no joke at
  all.
- **Truer:** In the coffee-against-tea argument, the honest answer is the
  one with conviction. Coffee drinkers defend their drink like a first
  choice, not a second one — and "A" is literally the first choice.
- **Clean:** "A" stands on its own as a whole answer, unmistakable, with
  nothing needed beside it. Exactly one character, exactly one letter.

## How it works

`main.py` is a deterministic Python 3.13 program using only the standard
library — no network, no randomness. It writes the single letter `A`
(UTF-8, no trailing newline) to `/output/entry.txt`, or to the path in the
`OUTPUT_PATH` environment variable when set, then reads the file back and
verifies it holds exactly one non-whitespace character before exiting.

Run it:

```sh
python3 main.py
```

Two runs were verified locally to produce byte-identical output:
exactly 1 byte, `A`.
